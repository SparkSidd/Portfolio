## 📌 Executive Summary

A clean, responsive, and high-performance interactive developer portfolio engineered with modern front-end best practices. Designed to present technical projects, systems architecture, hackathon initiatives, and research papers with zero bloat and smooth micro-interactions.

---

## 🚀 Key Features

- **⚡ Lightning Fast Runtime**: Powered by Vite + React 18, compiling lean optimized production bundles.
- **🎨 Glassmorphic & Modern Theme**: Tailored Tailwind CSS design system with subtle gradients, responsive typography, and adaptive dark mode elegance.
- **📱 Responsive Layout**: Fully optimized across ultra-wide monitors, tablets, and mobile viewports.
- **🛠️ Modular Component Architecture**: Clean separation between section views (Hero, About, Projects, Skills, Contact).
- **📬 Contact Integration**: Direct communication channels linked to GitHub, LinkedIn, and personal email.

## ⚡ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Compile optimized production build
npm run build
```
